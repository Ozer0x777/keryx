# ADR-0014 — Consultation de l'audit, référentiel MITRE, rétention

- **Statut** : accepté (20/11/2026) ; **durées de rétention à valider avec le DPO**
- **Journal d'audit consultable** : par l'Admin et le Manager. Le Manager ne voit que les entrées de ses clients. L'Admin voit toutes les entrées mais les détails des actions touchant au contenu (tickets, pièces, rapports, modèles) lui sont masqués, pour respecter la séparation administrateur / opérateur. Chaque consultation est elle-même journalisée. Le point de contrôle (numéro et sceau) se génère dans l'interface pour archivage hors de Keryx.
- **Référentiel MITRE** : import d'un fichier STIX 2.1 déposé par l'administrateur (aucun accès réseau sortant). Seuls les objets `attack-pattern` non révoqués et non dépréciés portant un identifiant `mitre-attack` valide sont retenus. Le référentiel renseigne nom et tactiques lors d'une correction manuelle ; il ne déduit rien automatiquement (décision du projet : pas de devinette).
- **Rétention** : seules les alertes brutes des tickets clos plus anciennes que la durée du client (12 mois par défaut, 6 mois minimum) sont supprimées ; ticket, registre des actions et pièces sont conservés. Simulation possible ; chaque purge est journalisée avec le nombre supprimé. Les pièces suivent leur propre cycle (restitution, destruction par un manager).
- **Exigences** : PDIS IV.3.9.c, IV.2.2.w ; ISO/IEC 27002 8.15 ; PRIS VI.2.4.
