# Schéma JSON de l'IODEF (RFC 8727, annexe B)

`iodef-2.0-rfc8727.schema.json` est la figure 6 de la RFC 8727 (« JSON Binding of the Incident Object Description
Exchange Format »), extraite du texte publié par le RFC Editor (https://www.rfc-editor.org/rfc/rfc8727.txt), sans
autre changement que la mise en forme : en-têtes et pieds de page du texte retirés, JSON réindenté, et le motif de
`URLtype`, coupé en deux lignes par la mise en page de la RFC, recollé. La RFC précise que
ce schéma est informatif ; il sert ici à valider l'export IODEF de Keryx dans les tests (`tests/test_iodef_schema.py`).
